# Blog Backup — blog.palharez.dev

This repository is a **versioned backup** of my blog posts from **blog.palharez.dev**.

## Why
- Keep an **owned archive** of my writing
- Track **history/diffs** of edits
- Make future **migration** easy

## What’s inside
- `posts/` — Markdown exports of posts
- `assets/` — images/files (optional)
- `meta/` — JSON metadata (optional)
- `scripts/` — backup/sync helpers (optional)

## How it’s updated
- Either via **Hashnode → GitHub integration**, or
- via a **custom sync script** (API-based)
